# Contributing

Thank you for improving StockAnalyzer.

1. Create a focused branch and keep changes scoped.
2. Never commit `.env`, credentials, or private market data.
3. Run the Angular, .NET, and Python test commands documented in the README.
4. Update API documentation and screenshots when user-facing behavior changes.
5. Keep predictions clearly labeled as educational and not financial advice.

Bug reports should include reproduction steps, expected behavior, actual behavior,
and relevant logs with secrets removed.
